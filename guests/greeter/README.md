# greeter

A guest module used as a test fixture. It exists so the host is tested against
something a real toolchain produced, rather than against a module written to fit
the host's assumptions.

The interface is in `wit/greeter.wit`. Bindings are generated by the
`wit-bindgen` macro at compile time, so `cargo` is the only tool needed.

```
cargo build --release --target wasm32-unknown-unknown
cp target/wasm32-unknown-unknown/release/greeter.wasm ../../core/src/test/resources/greeter.wasm
```

The built module is checked in so the Java tests run without a Rust toolchain
installed. CI rebuilds it from this source before running them, so the copy in
the repository cannot drift from what this code actually compiles to.
